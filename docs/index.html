01What it does

VoiceLab is a local Gradio + FastAPI playground for designing, auditing, and comparing ElevenLabs voice personas. You get a real UI for tuning stability, similarity boost, style, and speed — without writing a line of Python. The same codebase works without any API key: LocalTts uses the system's pyttsx3 engine so you can develop and run tests in CI with zero cloud credentials.

🎛

Design a persona

Pick from five built-in presets (or start blank) and dial in stability, similarity boost, style, and speed. Hear the result instantly.

⚖️

Compare two voices

Side-by-side compare tab synthesizes the same text through Voice A and Voice B simultaneously, with independent persona and settings per side.

🔑

Key-gated cloud features

Set ELEVENLABS_API_KEY to unlock live ElevenLabs synthesis and the Voice Cloning tab. Without it, system TTS keeps everything running.

🧪

17 tests, keyless

All 17 tests run without an ElevenLabs key or audio hardware — backends degrade gracefully, so CI never needs credentials.

02Architecture

The engine is the single decision point: it reads ELEVENLABS_API_KEY and returns either ElevenLabsTts or LocalTts. Gradio is mounted on FastAPI at /; the health endpoint at /healthz reports the active backend.

04Keyless vs keyed

The engine selects a backend at startup based on the presence of ELEVENLABS_API_KEY in the environment (or a .env file). The Gradio header always shows the active backend so there is no ambiguity.

Keyless (default)

  • Synthesize tab: system TTS via pyttsx3 (WAV)
  • Compare tab: both voices via pyttsx3
  • Voice list: system voices (or stub if pyttsx3 unavailable)
  • Backend banner: "Local system TTS (pyttsx3 fallback)"
  • All 17 tests pass — no audio hardware needed in CI
Voice Cloning tab shows a setup guide instead of the clone UI. Nothing breaks — it degrades with a clear message.

Keyed (cloud)

  • Synthesize tab: ElevenLabs cloud TTS (MP3, eleven_multilingual_v2)
  • Compare tab: both voices via ElevenLabs API
  • Voice list: all voices from your ElevenLabs account
  • Backend banner: "ElevenLabs (cloud)"
  • Voice Cloning tab: enabled (stub implementation; requires Professional plan)
Note: Voice cloning is a gated stub — it calls the ElevenLabs API but does not implement full error recovery or file validation. Requires an ElevenLabs Professional plan or higher.

05Quickstart

You need Python 3.12+ and uv.

terminal
# clone and install (base deps — no ElevenLabs key needed)
git clone https://github.com/arslankazmi/voicelab && cd voicelab
uv sync

# serve (keyless mode — system TTS fallback)
uv run voicelab serve --port 8001
# open http://localhost:8001

# to unlock ElevenLabs cloud synthesis:
uv sync --extra cloud
export ELEVENLABS_API_KEY=your_key_here
uv run voicelab serve --port 8001

# run tests (no key or audio hardware needed)
uv run pytest
17 passed

06Deploy

VoiceLab ships a Dockerfile and docker-compose.yml for one-command deployment. The image runs as a non-root user (uid 1000) on port 8001. The container health check polls /healthz every 30 s.

docker compose
# create .env with your key (omit for keyless mode)
echo "ELEVENLABS_API_KEY=sk-..." > .env

# build and start
docker compose up --build
# voicelab running at http://localhost:8001

# optional: add auth token
echo "AUTH_TOKEN=your-secret" >> .env

Supported .env keys:

ELEVENLABS_API_KEYunsetEnables cloud synthesis + voice cloning. Omit for keyless/local mode.
AUTH_TOKENunsetBearer token for /api/v1/* routes. Leave unset for open local use.

07API

The REST API lives at /api/v1. Interactive docs are at /docs (Swagger UI) and /redoc. All routes accept and return JSON unless otherwise noted. When AUTH_TOKEN is set, include Authorization: Bearer <token> on every request.

Routes

MethodPathRate limitDescription
GET/api/v1/voices60/minList available voices from the active backend.
GET/api/v1/personas60/minList built-in persona presets.
POST/api/v1/synthesize10/minSynthesize text → stream audio/mpeg. Body: text (max 5000 chars), voice, settings.
POST/api/v1/compare60/minSynthesize with two voices; returns base64 audio for each. Body: text, voice_a, voice_b, settings.
POST/api/v1/clone5/minClone a voice (ElevenLabs key + consent required). Multipart form: consent=true, voice_name, sample (audio file ≤ 15 MB / 120 s).

Voice cloning — consent gate

The /api/v1/clone endpoint requires an explicit consent=true field. Without it the request is rejected with HTTP 400. Cloning also requires ELEVENLABS_API_KEY (returns HTTP 501 if absent) and an ElevenLabs Professional plan or higher. Voice audio is biometric data — see PRIVACY.md.

curl examples
# synthesize
curl -X POST http://localhost:8001/api/v1/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello world","voice":"Rachel","settings":{"stability":0.75}}' \
  --output out.mp3

# compare two voices
curl -X POST http://localhost:8001/api/v1/compare \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello","voice_a":"Rachel","voice_b":"Adam"}'

# clone (requires key + consent)
curl -X POST http://localhost:8001/api/v1/clone \
  -F "consent=true" -F "voice_name=MyVoice" -F "sample=@sample.wav"
