# VoiceLab

ElevenLabs voice/persona design + comparison playground.

- Keyless mode: system TTS fallback via pyttsx3
- Cloud mode: ElevenLabs API (set `ELEVENLABS_API_KEY`)
- Compare two voices side-by-side
- Voice cloning tab (ElevenLabs key required)

## Quickstart

```bash
uv sync
uv run voicelab serve --port 8001
```

Open http://localhost:8001
